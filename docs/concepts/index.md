# Concepts

Understanding six ideas is enough to navigate confidently anywhere in Moire. You do not need to understand them all before you start — the [UI Tour](../tour/index.md) shows them in action first. But once you want to understand *why* the interface behaves the way it does, these pages are the place to look.

Each concept is explained with an everyday analogy before any technical term is introduced. Read them in order the first time; return to individual pages later as reference.

## In this section

- [Entities](entities.md) — the things in the graph: what they are, how they are displayed, and what levels of detail Moire shows.
- [Relationships](relationships.md) — the connections between entities: navigable links vs plain-text facts, outgoing vs incoming.
- [Types](types.md) — how entities are categorised into classes, and why those classes form a hierarchy.
- [Sets](sets.md) — working with groups rather than individuals: the core of what makes Moire distinctive.
- [The Lens](the-lens.md) — the combination of all active filters, and how changing the lens changes what you see without changing the data.
- [Layers](layers.md) — conceptual distance from a focus entity, and how Moire uses it to control the level of detail shown.
