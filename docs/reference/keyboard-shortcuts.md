# Keyboard Shortcuts

All keyboard shortcuts available in Moire.

## Global shortcuts

| Shortcut | Action |
|---|---|
| `⌘K` (Mac) / `Ctrl+K` (Windows / Linux) | Open the search palette |
| `Escape` | Close the search palette or any open dialog |

## Search palette

| Shortcut | Action |
|---|---|
| Start typing | Begin searching immediately — no need to click the input first |
| `↑` / `↓` | Move the highlighted result up or down |
| `Enter` | Select the currently highlighted result and navigate |
| `Escape` | Close the palette without navigating |

## Browser navigation

Moire's Back and Forward history integrates with the browser's standard navigation shortcuts:

| Shortcut | Action |
|---|---|
| `Alt+←` (Windows / Linux) | Back |
| `Alt+→` (Windows / Linux) | Forward |
| `⌘[` (Mac) | Back |
| `⌘]` (Mac) | Forward |

The Back (←) and Forward (→) buttons in the Moire top bar are clickable equivalents of the same actions.

## Accessibility

All interactive elements — entity cards, facet checkboxes, navigation buttons — are focusable via `Tab` and activatable with `Enter` or `Space`. The search palette opens on `⌘K` and closes on `Escape`, maintaining keyboard focus throughout.
